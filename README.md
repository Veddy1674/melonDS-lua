Fork of [melonDS](https://github.com/melonDS-emu/melonDS) with Lua scripting support via [sol2](https://github.com/ThePhD/sol2/releases).  
Allows scripts to be executed in-game and interact with the emulator, game memory, keybinds and savestates.
